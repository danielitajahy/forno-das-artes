# Guia rápido — apresentação aos avaliadores

1. Peça à administração um acesso APRESENTADOR liberado, com PIN e senha individual. Não compartilhe a senha nem a escreva no telão.
2. No notebook autorizado, entre em **Acesso → Acesso individual por PIN**. Digite PIN e senha adicional. Você verá somente a consulta consolidada.
3. Abra **Painel dos Avaliadores → Modo pitch**. Oito indicadores principais ficam em destaque. **Ver todos / principais indicadores** alterna a visão.
4. Para explicar um número, abra **Ver cálculo**. Para custos, ingredientes e margens, abra o bloco de detalhes por sabor.
5. Diga claramente: “São dados locais deste notebook, atualizados após as operações confirmadas”. Não diga que celulares diferentes estão sincronizados.
6. Se aparecer **Não apurado**, a informação necessária ainda não foi conferida/cadastrada. Não substitua por zero nem invente estimativas.
7. **Gerar PDF / imprimir prestação** abre o retrato daquele momento. Clique em **Imprimir / Salvar como PDF**, escolha **Salvar como PDF** e guarde o arquivo. Ele pode ser consultado sem internet. Um PDF salvo não se atualiza depois.
8. Ao terminar, saia do modo pitch, abra **Acesso** e encerre a sessão. Não use o acesso de administração para apresentar.

Para ensaiar com números fictícios, peça ao responsável a prévia local `PREVIA_AVALIADORES.html`. O PDF de exemplo é fictício e não representa o movimento da feira.

Aportes não são vendas. Saldo do caixa, margem por pizza e resultado operacional são medidas diferentes. Disponibilidade para doação é uma previsão depois das reservas, não uma transferência já feita.
